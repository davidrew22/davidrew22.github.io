# David Prakah-Asante’s portfolio

Open `index.html` in a browser to preview the site. The site uses plain HTML and CSS with local image assets. The optional Google Fonts have system-font fallbacks.

The images come from David’s LinkedIn profile, the live EventQuant homepage, the STARS Sobel filter comparison, and David’s photo of the live BerryWeather dashboard.

The section order and case-study structure draw on [Yewon Choi’s portfolio](https://yewon316.github.io/).

To publish the portfolio, place the contents of this directory at the root of the `davidrew22/davidrew22.github.io` repository. In the repository’s Pages settings, select **Deploy from a branch**, then choose **main**, **/(root)**, and **Save**. [GitHub Pages publishing documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
